# Next milestone: data a club would need

| To answer | Minimum data |
|---|---|
| How many booked places are used | Check-ins per session |
| How much demand a full class turns away | Waitlist joins, promotions and drop-offs |
| Whether late cancellations drive empty places | Booking and cancellation timestamps |
| Calibrated P(full) and booking limits | The above, plus planned timetable changes and room capacity |
| Whether moving a class creates or shifts demand | Planned, ideally randomized, timetable changes across centres |

Any real club data must be anonymized and used only with the club's written permission.
