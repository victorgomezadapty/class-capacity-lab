A booked place is not an occupied place.

Una plaza reservada no es una plaza ocupada.

Group classes are planned around bookings, but revenue, coaching time and member experience depend on who actually shows up. This lab measures the gap between booked demand and realized attendance, tests which operational variables travel with it, and defines the data a real gym would need to forecast and manage capacity.

Las clases grupales se planifican con base en reservas, pero los ingresos, el tiempo del coach y la experiencia del socio dependen de quién llega de verdad. Este laboratorio mide la brecha entre la demanda reservada y la asistencia real, prueba qué variables operativas la acompañan y define los datos que un gimnasio real necesitaría para predecir y gestionar su capacidad.

01

The operational problem

El problema operativo

When a class shows full, members join waitlists or give up. When half of those places stay empty, the club has turned members away from capacity it already paid for. Airlines and clinics manage the same tension with no-show forecasting and controlled overbooking, but those tools only work when attendance is measured per session and the forecasts are calibrated.

Cuando una clase aparece llena, los socios entran a lista de espera o desisten. Cuando la mitad de esas plazas queda vacía, el club ha rechazado socios con una capacidad que ya estaba pagando. Aerolíneas y clínicas gestionan esta misma tensión con predicción de no-shows y sobreventa controlada, pero esas herramientas solo funcionan si la asistencia se mide por sesión y las predicciones están calibradas.

This milestone is deliberately descriptive: before predicting anything, establish what the data can and cannot say.

Este hito es deliberadamente descriptivo: antes de predecir nada, hay que establecer qué pueden decir los datos y qué no.

Right statistic for the data

La estadística adecuada a cada dato

Point-biserial correlation for numeric vs. binary; Cramér’s V for categorical, never arbitrary numeric codes for categories. Set-based support, confidence and lift for multi-select preferences.

Correlación punto-biserial para numérica vs. binaria; V de Cramér para categóricas, nunca códigos numéricos arbitrarios. Soporte, confianza y lift sobre conjuntos para preferencias de selección múltiple.

Uncertainty everywhere

Incertidumbre en todo

Deterministic 1,000-resample percentile bootstrap for every coefficient, Wilson intervals for rates, small-cell warnings, and intervals withheld when strata are too sparse.

Bootstrap percentil determinista de 1.000 remuestreos para cada coeficiente, intervalos de Wilson para tasas, alertas de celdas pequeñas e intervalos omitidos cuando los estratos son escasos.

Confounding before conclusions

Confusión antes que conclusiones

Direct standardization over five tenure strata and a linear partial correlation test whether schedule and lead-time patterns survive once member composition is held constant.

Estandarización directa en cinco estratos de antigüedad y una correlación parcial lineal comprueban si los patrones de horario y anticipación sobreviven al fijar la composición de socios.

What this lab does not claim.Lo que este laboratorio no afirma. No causal effects, no fitted prediction model, no utilization figures for a real club and no overbooking recommendation. Dataset B is synthetic and is never merged with Dataset A. The public site ships aggregated counts only; raw GoalZone rows are not redistributed. Sin efectos causales, sin modelo predictivo ajustado, sin cifras de utilización de un club real y sin recomendación de sobreventa. El Dataset B es sintético y nunca se combina con el Dataset A. El sitio público solo publica conteos agregados; no se redistribuyen las filas crudas de GoalZone.

05

Reproducible by design

Reproducible por diseño

Python (pandas, pyarrow) builds every table, document and the dashboard from the source CSVs. The dashboard is a single self-contained HTML file with hand-written SVG charts, keyboard-accessible, printable and usable offline. An executed public Kaggle notebook reproduces the association analysis with identical results.

Python (pandas, pyarrow) genera cada tabla, documento y el dashboard a partir de los CSV de origen. El dashboard es un único HTML autocontenido con gráficos SVG hechos a mano, accesible por teclado, imprimible y usable sin conexión. Un notebook público ejecutado en Kaggle reproduce el análisis de asociaciones con resultados idénticos.
